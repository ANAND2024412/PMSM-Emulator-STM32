
# PMSM Emulator using STM32

## Overview
Real-time PMSM emulator implemented using STM32 to simulate motor behavior for control system testing.

## Features
- PWM generation using timers
- ADC input sensing
- UART monitoring (PuTTY)
- Stable speed emulation

## Tools & Tech
- STM32
- Embedded C (HAL)
- MATLAB/Simulink
